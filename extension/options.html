Chat On Steroids companion

Remote browser bridge

Optional

Use this only when ChatGPT is open in this browser but Chat On Steroids is running on another machine. Leave it disabled for the normal same-machine setup.

Security model

Remote mode does not expose the MCP server or bypass conversation identity. The browser still receives the normal app bearer token through /pair; the remote secret only gates the additional network hop.

Prefer an encrypted private network such as Tailscale, or put the sidecar behind HTTPS. The extension asks Chrome for access only to the exact origin you save here.
